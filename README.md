# 🏸 北醫大 AR 導引

使用 MindAR + Three.js Module 製作的 WebAR 導引。

使用者透過手機瀏覽器開啟網站，
允許相機權限後，
對準指定場景圖片即可進行 AR 辨識與方向導引。

---

## 技術

- HTML
- CSS
- JavaScript
- Three.js
- MindAR
- Netlify
- GitHub
